# 🖥️ IT Asset Management System

A modern, **100% offline** IT Asset Management System — single HTML file, no server needed!

[![Live Demo](https://img.shields.io/badge/demo-live-success)](https://athithyan-murugesan.github.io/it-asset-manager/)
[![License](https://img.shields.io/badge/license-MIT-blue)](LICENSE)
[![Offline](https://img.shields.io/badge/offline-100%25-brightgreen)]()

## ✨ Features

- 📊 **Live donut chart** — Working vs Not Working status
- 📥 **Import from Excel** — with smart duplicate handling
- 📤 **Export to Excel** — formatted columns
- ✏️ **Add / Edit / Delete** assets
- 🔍 **Live search** across all fields
- 💾 **Auto-save** to browser (no data loss)
- 🎨 **Professional corporate UI**
- 📱 **Responsive** design
- 🔒 **100% offline** — runs in airplane mode

## 🚀 Quick Start

1. **Clone** or **download** this repository
2. **Double-click** `index.html`
3. Browser opens — start managing assets!

| Status | No |
| Remarks | No |

### 🔄 Round-Trip Workflow

1. **Export** → Excel file downloads
2. Edit in Excel / LibreOffice
3. **Import** the same file back
4. Existing Asset Tags are **updated**, new ones are **inserted**

No duplicates. Perfect merge.
